Outlook SMTP Auth Issue — Microsoft has disabled this by default
Solution 1 (Recommended):Use Gmail — create a free Gmail account for company notifications, Enable 2FA, Generate App Passwordand enter it here.
Solution 2:Microsoft 365 Admin → Settings → Org Settings → Modern Auth → Enable SMTP AUTH
Solution 3:Exchange Admin Center → Recipients → Mailboxes → Enable SMTP AUTH for user
Outlook SMTP Auth Error (535)?
Microsoft has disabled Basic SMTP Auth by default. Fix options:
1. Use Gmailwith App Password (recommended)
2. Enable SMTP AUTH: Microsoft 365 Admin → Settings → Org Settings → Modern Auth → Allow SMTP AUTH
3. App Password: Microsoft account → Security → Advanced security → App passwords
4. Use Port 587with your email + App Password in the password field
Gmail users: Use App Password (not your regular password)
Go to: Google Account → Security → 2-Step Verification → App Passwords
Gmail requires the From Email to match the login Username — leave this blank unless your provider (e.g. SendGrid, Amazon SES) explicitly supports sending from a different address.
